# NFC Business Card
Android app for HONOR 600 with MagicOS Quick Settings tile, NFC/HCE diagnostic, vCard QR code and VCF export.
## APK
Open **Actions → Build Android APK → latest successful run → Artifacts → NFCBusinessCard-APK**.
HCE requires a compatible custom APDU reader; normal NFC tap-to-share is not universally supported.
